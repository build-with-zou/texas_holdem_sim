# 德州扑克纯概率模拟

这个目录是概率统计课程论文的代码实现。当前版本是**纯概率基线模型**：

- 每局使用一副 52 张牌；
- 每位玩家发 2 张底牌；
- 发出 5 张公共牌；
- 所有玩家都不弃牌、不下注、不诈唬，直接摊牌比较最大 5 张牌；
- 统计不同上桌人数下，固定 0 号玩家的胜率、独赢率、平局率，以及最终获胜牌型分布。

这个模型不是完整德州扑克策略模型，而是后续加入位置、玩家性格、下注规则之前的 baseline。

## 环境配置

在本目录下执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 运行模拟

默认对 2 到 10 人桌分别模拟 5000 局：

```bash
python simulate.py
```

也可以指定模拟次数和玩家人数：

```bash
python simulate.py --trials 50000 --players 2 6 9 --seed 261
```

## 输出文件

运行后会生成 `outputs/` 目录：

- `summary_by_player_count.csv`：不同人数下的胜率、独赢率、平局率；
- `winning_hand_distribution.csv`：不同人数下最终获胜牌型分布；
- `win_probability_by_player_count.png`：胜率随玩家人数变化图；
- `tie_rate_by_player_count.png`：平局率随玩家人数变化图；
- `winning_hand_distribution_[N]_players.png`：每种人数场景下的获胜牌型分布图；
- `winning_hand_distribution_comparison.png`：不同人数下获胜牌型分布的汇总对比图。

## 当前模型的解释边界

当前版本回答的问题是：

> 如果所有玩家都一直留到最后，随机发牌本身会导致怎样的胜率与牌型分布？

它暂时不回答：

- 按钮位、大盲位等位置优势；
- 玩家是否弃牌；
- 下注、加注、跟注；
- 玩家性格，如紧、松、激进、保守；
- 长期收益与筹码变化。

这些会作为下一阶段策略模型加入。

## 策略模型的基础实现

当前已新增 `poker_game.py`，为后续策略实验提供基础框架：

- `GameState` 保存按钮位、盲注、筹码、底池、公共牌、当前下注额和行动顺序；
- `PlayerState` 保存每位玩家的筹码、弃牌、全押和本轮/全局投入；
- 支持翻牌前、翻牌、转牌、河牌四个下注阶段；
- 支持弃牌、过牌、跟注、下注、加注和全押，并检查当前动作是否合法；
- 支持结束下注轮并推进到下一街。

该模块暂时不决定玩家应该采取什么动作，玩家策略和牌力估计将在下一步接入。

## 起手牌强度实验

使用 `preflop_equity.py` 可以在指定人数下计算 169 类标准起手牌的条件权益。例如 6 人桌：

```bash
.venv/bin/python preflop_equity.py --players 6 --trials 5000 --seed 261 \
  --output outputs/preflop_strength_6_players.csv
```

`relative_to_average` 是该起手牌权益与理论平均权益 `1 / 玩家人数` 的比值：比值至少为 1.5 判为强牌，0.75 到 1.5 判为中等牌，低于 0.75 判为弱牌。模拟次数越多，牌力排序越稳定。

## 翻牌前性格策略

`personalities.py` 提供 `PreflopTable.lookup`、`action_probabilities` 和
`choose_action`。玩家的 `hole_cards` 使用 `holdem.py` 的牌 ID，
`personality` 使用 `Personality` 枚举；默认紧弱，可为每位玩家分别设置。
查表使用本局初始人数（2–10），对手弃牌后仍沿用原人数，避免将有选择地
留下的对手误当成随机对手。牌力为权益乘人数，≥1.5 为强牌，≥0.75 为中等牌。

以下概率是人为设定的实验参数，不是拟合结果。元组顺序是强牌、中等牌、弱牌：

| 性格 | 面对跟注成本时继续概率 | 继续后主动下注/加注概率 |
|---|---|---|
| 紧弱 | 95%、20%、5% | 10%、5%、1% |
| 紧凶 | 95%、20%、5% | 80%、50%、20% |
| 松弱 | 99%、80%、40% | 10%、5%、1% |
| 松凶 | 99%、80%、40% | 80%、50%、20% |

每次行动重新抽样；继续且不主动加注时跟注。可以免费过牌时始终继续，
按第二组概率下注/加注，否则过牌；不能加注时将这部分概率归入跟注/过牌。
上表为底池3、跟注2时的基准参数；其他下注状态会根据跟注成本与加注成本调整，见文末。
当前不考虑位置、对手范围、历史行动，且拒绝在翻牌后使用起手牌表。
独立推断实验不设筹码上限；旧游戏引擎仍保留筹码限制，短筹码跟注可能全押。

```python
import numpy as np
from personalities import Personality, PreflopTable, choose_decision
from poker_game import create_game

game = create_game(6)
player = game.players[game.to_act]
player.hole_cards = (12, 25)  # Ac Ad
player.personality = Personality.TIGHT_AGGRESSIVE
rng = np.random.default_rng(261)
table = PreflopTable()
action, amount = choose_decision(game, table, rng)
game.apply_action(action, amount)
```

验证：`.venv/bin/python -m unittest discover -s tests -v`。
这只是决策接口，完整下注轮结束判断、全押重开加注和边池结算仍需完善后才能进行收益实验。

## 六人桌贝叶斯首次行动实验

运行 `.venv/bin/python bayes_preflop.py --trials 100000 --seed 261`。
结果位于 `outputs/bayes_6_players/`：`prior.csv` 保存先验，
`posterior_comparison.csv` 保存观察似然、理论后验、模拟后验和样本数，
`prior_posterior.png` 对比先验与观察后的分布（柱为理论值、黑线为模拟频率）。

固定观察者底牌 Ac Kc，目标是六人桌翻牌前第一个行动者（非盲注位）。
底池3、目标跟注需2，目标可弃牌、跟注2、加注到4/6/10。
先枚举排除观察者底牌后的1225个对手底牌组合，按六人桌权益表归为强/中/弱。
其余四位玩家的隐藏牌边缘化，不需要发出；目标行动之前无其他行动信息。
本实验不设置筹码上限、不使用全押，只研究一次行动，不运行整局结算。

行为模型沿用 `POLICIES` 的继续概率和继续后的进攻概率。
选择进攻后，再按下表随机选择加注金额：

| 性格组 | 牌力 | 加注到4 | 加注到6 | 加注到10 |
|---|---|---|---|---|
| 紧弱、松弱 | 强 | 60% | 30% | 10% |
| 紧弱、松弱 | 中 | 75% | 20% | 5% |
| 紧弱、松弱 | 弱 | 85% | 13% | 2% |
| 紧凶、松凶 | 强 | 20% | 40% | 40% |
| 紧凶、松凶 | 中 | 40% | 40% | 20% |
| 紧凶、松凶 | 弱 | 55% | 30% | 15% |

例如 P(加注到10 | 强牌、紧凶) = 0.95 × 0.80 × 0.40。
`update_posterior` 只接收先验和观察似然，不接收真实底牌。
四种性格各独立抽样10万次，真实底牌仅用于统计观察后的经验牌力分布。
这是同一已知生成模型下的计算验证，不是现实玩家性格或策略有效性的实证；
金额概率是人为假设，牌力分类还包含原5000局权益表的抽样误差。
金额生成与似然计算现已共用 `personalities.decision_likelihoods`；
旧引擎通过 `choose_decision` 接收动作和实际额外投入，完整下注轮逻辑仍需完善。

## 动作与金额的信息增益对照

运行 `.venv/bin/python information_gain.py`，默认六人桌、观察者 Ac Kc，
复用原有权益表及首次行动模型，不增加蒙特卡洛模拟。
可通过 `--players` 和 `--hero-cards` 扩展；人数变化时仍使用相同的
首次行动条件（底池3、跟注2）和人为行为模型。
结果保存到 `outputs/information_6_players/`：

- `information_summary.csv`：每种性格的动作信息、金额额外信息和剩余不确定性。
- `observation_details.csv`：每个观察的概率、先验、后验、熵差和KL散度。
- `information_gain.png`：动作信息与金额额外信息的堆叠图。

令 H 为强/中/弱牌等级，A 为弃牌/跟注/加注，B 为金额档位，性格 S 已知。
使用以2为底的 Shannon 熵，单位为bit：

- 动作信息：I(H; A | S) = H(H) − E_A[H(H | A, S)]。
- 总信息：I(H; A, B | S)。
- 金额额外信息：I(H; B | A, S) = 总信息 − 动作信息。

本场景弃牌和跟注没有可变金额，因此金额额外信息等于
P(加注 | S) × I(H; B | 加注, S)。表中的
`amount_information_given_raise_bits` 是已知发生加注时的金额信息，
`amount_extra_information_bits` 是对所有首次行动平均后的金额信息。
`uncertainty_reduction_fraction` 为总信息除以先验熵。
单次观察的熵可能比先验更大；平均信息增益非负，不能把单次熵差当作KL散度。

当前先验熵为1.172375 bit。四种性格的总信息分别为紧弱0.170097、
紧凶0.192581、松弱0.137002、松凶0.190001 bit；金额的额外贡献分别为
0.000269、0.006158、0.000507、0.010908 bit。
这些值在固定行为模型和权益表下精确枚举得到，仍受人为策略参数和
原权益表抽样分类影响，不能解释为真实玩家的一般规律。


## 根据跟注与加注成本调整行为

`BettingContext` 记录行动前的底池、当前最高下注、本人本轮已投入、
最小加注增量和大盲注。待跟注额 C = 当前最高下注 − 本人本轮已投入，
价格 q = C / (P + C)，其中 P 是行动前底池（含其他人的已有下注）。
不直接用筹码绝对值决定贵贱：同比例放大所有筹码不改变概率。

基准为 P=3、C=2，即 q0=0.4。继续概率为：

`c = min(1, c0 * exp(-k * (q - 0.4)))`。

其中 c0 来自原四种性格；强/中/弱牌的 k 基础值分别为2/6/10，
紧型乘1.2，松型乘0.7。免费过牌时 c=1。
因此相对底池越贵越少继续，中弱牌对价格更敏感；跟注不是由权益与
价格直接硬比较，这里仍是概率行为模型，不是最优决策算法。

先按基准进攻概率 a 和原金额权重 w_j 分配候选加注，再计入加注成本：

- 跟注后的底池 B = max(P+C, 大盲注)。
- 三档加注增量 R_j = max(合法最小增量, ceil(f_j * B))，f=(0.4,0.8,1.6)。
- 金额标签使用本轮总下注目标：当前最高下注 + R_j；实际本次投入还要减去本人已投入。
- 每档成本折扣 d_j = exp(-k * max(0, R_j/B − f_j))。
- 弃牌概率 = 1−c，各档加注概率 = c*a*w_j*d_j，跟注/过牌概率 = c−各档加注概率之和。

最低合法增量使候选金额高于参考成本时，玩家会少选该金额；省下的加注概率
归入跟注/过牌。此处分配和式子共同定义了联合行为分布，可等价为先抽动作、
再在选定的加注档位间按条件概率抽金额。重合金额合并成一个可见观察。
这些敏感系数和金额档位均为实验设定，尚未用现实数据拟合。

`choose_decision` 同时返回动作和投入金额，供引擎应用。
旧 `choose_action` 只返回动作，保留为兼容接口，无法传递随机金额。
贝叶斯实验和信息分析均接受以下公开状态参数，例如面对加注到10：

```bash
.venv/bin/python bayes_preflop.py --pot 13 --current-bet 10 --min-raise 8 \
  --output-dir outputs/bayes_price_aware/facing_raise_10
.venv/bin/python information_gain.py --compare-prices
```

价格对照结果位于 `outputs/price_comparison/`，有基准、面对加注到10、面对加注到40三组。
这三组是固定相同先验、改变公开价格的独立情境对照，不是同一局连续更新：
尚未根据此前加注者的行为修正目标玩家先验，也不模拟其他玩家决策。
每个情境内推断均使用对应价格的似然；旧基准结果得以保留。
新增模拟结果位于 `outputs/bayes_price_aware/`，每种性格各10万次。


## 最小可结算牌局

`preflop_hand.py` 实现2–10人有限加注的单局实验：
发牌 → 收取盲注 → 翻牌前依次行动 → 弃牌直接获胜或发完公共牌摊牌 → 结算。
每局不设置筹码上限、不使用全押、不发生边池；不进行翻牌后的下注。
默认盲注1/2，每轮最多3次主动加注（盲注不计），达到上限后只能弃牌、跟注或过牌。
这是限制加注次数的研究模型，不是完整无限注德州扑克规则。

状态包含底牌、位置、已知性格、弃牌状态、本轮/累计投入、底池、当前最高下注、
最小加注增量、待行动玩家、加注次数、公开行动历史与随机种子。
`DecisionView` 仅向策略提供自己的底牌和公开信息：对手底牌和预生成公共牌均不暴露。
位置目前决定盲注及行动次序，策略概率尚未额外加入位置系数。
按钮每局轮换；发牌与各座位决策使用独立随机数流，便于之后配对比较不同策略。

`poker_game.py` 已改用待行动集合结束下注轮，保留大盲的过牌/加注机会，
加注后重新等待未跟齐的玩家，避免新一街零投入就立即结束。
`starting_stack=None` 表示无筹码上限；原有限筹码接口保留，
但最小牌局只走无全押路径，不能据此宣称完整边池与全押规则已经实现。

结算计入弃牌者已投入的筹码；退回最高下注中无人匹配的部分，再分配有效底池。
平局均分，余数筹码按按钮左侧开始的座位顺序分配。
每位玩家净收益 = 分得底池 + 退回筹码 − 总投入；无抽水，全桌净收益之和必须为0。
只剩一人时立即结算，不翻开公共牌。相同牌局不能重复结算。

```bash
# 0号使用随机策略，其余使用性格策略；保存完整单局日志
.venv/bin/python preflop_hand.py --policy mixed --seed 261 \
  --output-dir outputs/minimal_preflop/demo
# 运行功能验证批次，轮换按钮
.venv/bin/python preflop_hand.py --hands 200 --policy mixed --seed 261 \
  --output-dir outputs/minimal_preflop/validation
```

也可使用 `--policy random`（全员随机）、`--policy personality`（全员性格策略）
或 `--policy informed`（全员数据驱动策略）。默认 `mixed` 让 0 号玩家使用
数据驱动策略，其余玩家使用性格策略。
随机策略不读取底牌，对允许的动作等概率选择；免费过牌时不主动弃牌，
选加注后对不同金额档等概率选择。性格策略沿用起手牌查表及价格敏感概率，
加注达到上限后将主动概率转入跟注/过牌。后续新增策略只需实现
`policy(view, rng) -> (action, 本次额外投入)`，由 `play_hand` 调用。
数据驱动策略会读取自己的起手牌权益、公开的对手性格和行动历史：先用每个对手
的性格条件似然顺序更新强／中／弱后验，再把活跃对手的强牌风险折扣到自己的
条件权益；若权益低于当前跟注价格则弃牌，权益明显占优时加注，否则跟注/过牌。
这是透明的第一版可解释策略，仍是近似模型，不是完整的最优策略求解。

输出 `hands.jsonl` 逐局记录牌面、位置、性格、实际策略、行动前状态、
投入、退回、获奖和净收益；日志中的全部底牌仅供局后分析，不能传回策略。
`summary.json` 汇总收益及结束原因。200局功能验证为182局摊牌、18局其他人全弃，
全部满足零和结算；该小批次不能用于判断某种策略是否更赚钱。

策略信息边界：行动时所有玩家都知道彼此的性格、位置和公开行动；每个玩家只知道
自己的底牌，不能看到其他玩家底牌或尚未发出的公共牌。结算后的 JSON 日志为了研究
和复盘会公开所有底牌及公共牌，这不代表它们在行动时可见。如果让玩家行动前知道
所有底牌，就不再是贝叶斯推断实验，而是完全信息策略实验。
